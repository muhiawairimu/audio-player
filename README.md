# 🎵 SoundWave — Audio Player & Podcast Hub

An interactive, custom-styled web audio player and podcast hub built with HTML5, CSS3 (Tailwind CSS), and JavaScript using native browser Audio APIs.

---

## ✨ Features

- **Custom Audio Engine:** Native HTML5 Audio API integration for custom playback controls (play/pause, next/previous track, volume slider).
- **Interactive Progress Scrubber:** Real-time track position indicator with click-to-seek functionality and formatted MM:SS timestamp displays.
- **Dynamic Playlist Queue:** Interactive track list rendering with active state highlights and instant track switching.
- **Responsive Dark Theme:** Sleek glassmorphism-inspired dark interface optimized for mobile and desktop screens.
